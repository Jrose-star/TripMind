# 多智能体旅行规划 Agent

基于 LangGraph + FastAPI + MCP 的旅行规划写作 Agent，支持意图解析、POI 检索、行程编排、预算校验、攻略写作输出。

## 技术栈

- **Agent 编排**：LangGraph
- **服务层**：FastAPI
- **存储**：PostgreSQL + Redis + pgvector
- **工具协议**：MCP（先空壳，后接真实高德/天气）
- **可观测**：LangSmith / Langfuse
- **前端**：Web UI（全栈）
