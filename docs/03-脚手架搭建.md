# 阶段三：项目脚手架搭建

> 状态：已完成 · 日期：2026-11-10

## 技术选型最终确认

| 项 | 选择 |
|----|------|
| Python 环境 | uv（0.13.7） |
| Python 版本 | 3.13（本机），语法按 3.11+ |
| 后端 | FastAPI + LangGraph |
| 前端 | React 18 + Vite 5 |
| 依赖管理 | `pyproject.toml`（后端）+ `package.json`（前端） |

## 目录结构

```
agentsproject/
├── docs/                    # 阶段文档
├── backend/
│   ├── app/
│   │   ├── main.py          # FastAPI 入口
│   │   ├── config.py        # 配置（pydantic-settings）
│   │   ├── api/             # health.py + plan.py
│   │   ├── agents/          # state.py + graph.py + nodes/
│   │   ├── schemas/         # Pydantic 模型
│   │   ├── tools/           # MCP 客户端（预留）
│   │   ├── db/              # PG/Redis（预留）
│   │   ├── llm/             # 模型可插拔层
│   │   └── observability/   # LangSmith/Langfuse（预留）
│   ├── tests/               # 基础测试
│   ├── pyproject.toml
│   └── .env.example
├── mcp/
│   └── server.py            # MCP 空壳 Server
├── frontend/                # React + Vite
└── README.md
```

## 本阶段交付

- FastAPI 应用 + `/api/health` 健康检查
- LangGraph 5 节点空壳图（可编译、可运行）
- MCP 空壳 Server（search_poi / get_weather 占位工具）
- 前端 React 页面（输入需求 → 调 `/api/plan`）
- 依赖清单 + `.env.example`（仅字段名，无真实值）

## 待接入（后续阶段）

- 真实 MCP（高德地图 / 天气）
- PostgreSQL / Redis / pgvector 连接
- SSE 流式输出
- LangSmith / Langfuse 可观测
- Docker Compose

## 启动方式

```bash
# 后端
cd backend
uv sync
uv run uvicorn app.main:app --reload --port 8000

# 前端
cd frontend
npm install
npm run dev
```
